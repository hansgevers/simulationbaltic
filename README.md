# simulationbaltic
Code an materials for the paper "Financial Sustainability of the Care for the Disabled: A Simulation of Benefits for Older People in the Baltic States up to 2050 Powered by SHARE and Eurostat"

To support reproducibility of the study, following do-files are available:

- "do.do" as the Stata file for data preprocessing & preparation, descriptives, and analysis
- "output.pdf/.smcl" as the log of the do.do execution
- the used Eurostat data, yet the SHARE-package requires registration
- the published illustrations

Relevant hyperlinks: www.share-eric.eu www.stata.com

Author: Hans Gevers - https://orcid.org/0009-0001-0249-4142
